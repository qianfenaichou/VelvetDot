# 05 · FAQ 与参赛规则

## 一、官网常见问题

| 问题 | 官方答复要点 |
|---|---|
| 高水平创新方向的企业赛道可提交视频等辅助材料吗？ | 可以。辅助材料整体不超过 450MB，支持 PPT、宣传册、mp4/mov/mpg/f4v/m4v/flv/mkv/rmvb/wmv/avi 等视频格式，内容不涉密。 |
| 1 个参赛项目可以跨赛道报名吗？ | 不可以。每个参赛项目限报 1 个比赛方向下的 1 个赛题，一经选定不得更改。 |
| 报名时间具体到什么时候？ | 2026 年 11 月 8 日 24:00 准时结束，避免临近时刻网络拥堵。 |
| 在校学生、企业员工、科研院所人员可以跨单位组队吗？ | 可以。高校赛道要求团队牵头人须为在校学生，其余赛道无特定要求。 |
| 一个团队有团队人数上限或下限吗？ | 部分赛道有。高校赛道最多 3 名；玄铁赛道也有限制；其余赛道暂无明确限制。本赛题官网设置 1–6 人。 |
| 同一个单位/高校可以多支队伍报多个赛道吗？ | 可以。但每个赛道的项目方案必须相互独立，不能雷同或相似。 |
| 项目必须是全新开发吗？已发表论文、已参加其他赛事、已商业化落地的项目能否参赛？ | 不是必须。原则上均可参赛，但不得侵犯他人专利权、著作权、商标权及其他知识产权，不得违反法律法规。 |
| 预赛、选拔赛都是线上评审，需要线上答辩吗？ | 不需要。按目前流程，预赛、选拔赛都是材料评审。 |
| 参赛提交内容提到的需要提交代码在相应位置是哪里？ | 赛题说明了提交位置就按说明上传；未说明可放在“其他材料”附件。 |
| 什么是预赛完赛证书？如何获得？ | 完成赛题并在大赛网站提交，通过格式审查即可申领，不论得分高低。 |
| 什么是指导教师证书？ | 仅限高校学生参赛团队，在选拔赛、总决赛阶段均可获得。 |
| 选拔赛与总决赛证书如何获得？ | 选拔赛证书需得分靠前并晋级总决赛；总决赛证书需到现场参赛并入选优胜奖或专项奖。 |

## 二、参赛团队规则（参赛手册）

1. 参赛团队可以是个人或单位。个人须具备完全民事行为能力；单位须是具有独立法人资格的企业、事业单位、科研院所、高校等组织机构。允许来自不同单位的个人合作组队，以及不同单位合作组队报名。个人组成的团队须指定 1 人为牵头人，单位组成的团队须指定 1 个单位为牵头单位，牵头人和牵头单位均须在大赛网站使用真实信息完成注册。
2. 被列入“信用中国”网站记录失信被执行人、重大税收违法案件当事人名单、政府采购严重违法失信行为记录名单的个人和单位不得参赛。
3. 同一参赛单位可以有多个团队参赛（不限制方向、赛道、赛题），每个参赛团队可以向不同的比赛方向、赛道、赛题分别提交不同的参赛项目。
4. 每位参赛代表（个人和单位）只能代表 1 个团队参加比赛。报名截止之后，参赛代表不可更改。
5. 参赛团队须遵守大赛规则，对所有信息的准确性和真实性负责。提供虚假信息将被注销比赛资格、取消成绩、收回相关奖励。

## 三、参赛项目规则

1. 每个参赛项目限报 1 个赛题，一经选定不得更改。
2. 知识产权归参赛团队；不得侵犯他人专利权、著作权、商标权及其他知识产权；违者取消资格和成绩。
3. 项目名称由团队自拟，须遵守法律法规和公序良俗。
4. 选拔赛、总决赛期间可在不改变项目名称和主要内容的前提下迭代，并在规定时间内更新材料。
5. 评审期间须按要求补充材料；所有已提交材料默认不退还。

## 四、报名与提交步骤

1. 打开 https://rv.cie.org.cn/home，右上角“注册/登录”，选择“中国电子学会用户登录”。
2. 完善资料：在校生填写学校名称、学信网截图、指导老师；非在校生填写单位名称、身份证、信用中国信息。
3. 创建或加入团队：个人团队或单位团队；队长负责报名。
4. 首页“赛事内容” → “RISC-V 高水平应用方向” → “CIE-香山社区” → 赛题详情 → “立即报名”。
5. 个人中心 → 我的参赛 → 切换“预赛” → “更新项目” → 上传材料（红星必填）。
6. 每个阶段以最后一次成功提交的资料为准。

## 五、评审与证书

- 预赛、选拔赛：线上材料评审，无答辩。
- 总决赛：线下现场讲演，可能需实物展示，接受评审委员会现场提问。
- 证书：预赛完赛证书（申领）、选拔赛晋级证书、总决赛奖励证书、指导教师奖励证书。
- 香山赛道奖金：钻石 5000 元（1 项）、铂金 3000 元（≤5 项）、金奖 1000 元（≤10 项）、银奖 500 元（≤20 项），含税。
- 其他激励：实习就业内推、能力等级证书、高校推免/考研复试推荐信、开发板套件、笔记本套件（指导教师）、高端会议/行业活动席位。
